# Plan: Replace TS SDK query() with direct claude -p

## Goal

Remove the `@anthropic-ai/claude-code` SDK dependency from the test runner by replacing the `query()` call in `start-test.ts` with a direct `claude -p` subprocess spawn. The TS orchestrator (index.ts), MCPStateServer, reporter, topo sort, and all other components remain unchanged.

## Why

1. Eliminates vendor-locked SDK dependency (`@anthropic-ai/claude-code`)
2. `query()` literally spawns `claude -p` under the hood — we're removing an indirection layer
3. Direct subprocess gives us control over `--output-format`, error handling, and future Python migration
4. Aligns with Phase 1's `agent_loop()` which also wraps `claude -p`

## Tasks

### Task 1: Rewrite `start-test.ts` to use `child_process.spawn`

**Files:** `cli/src/prompts/start-test.ts`

Replace:
- `import { query } from "@anthropic-ai/claude-code"` → `import { spawn } from "child_process"`
- `resolveClaudeCliPath()` → simplified to `which("claude")` (no SDK cli.js needed)
- `query({...})` → `spawn("claude", ["-p", prompt, "--output-format", "stream-json", ...])`
- Write MCP config to temp file, pass via `--mcp-config`
- Pass `--allowed-tools`, `--system-prompt`, `--model`, `--max-turns`, `--permission-mode bypassPermissions`
- Stream stdout lines, yield parsed JSON messages to match existing `for await` consumer
- Strip `ANTHROPIC_API_KEY` from subprocess env (OAuth enforcement)
- Clean up temp MCP config file on exit

**Return type stays:** `AsyncGenerator` yielding message objects — `index.ts` doesn't change.

### Task 2: Remove `@anthropic-ai/claude-code` from package.json

**Files:** `cli/package.json`

Remove `"@anthropic-ai/claude-code"` from dependencies. Keep all other deps (playwright, MCP SDK, express, etc.).

### Task 3: Verify build compiles

**Action:** `cd cli && bun install && bun build --compile ./src/index.ts --outfile ./dist/cc-test-runner --target bun`
